# Harmony Wake v7.1

Harmony Wake 是一个针对 Android / HarmonyOS 4 兼容层设计的定时唤醒与自动化工具。

## v7 / v7.1 新功能

- 保留 v6 已验证成功的系统闹钟广播 -> WakeLock 亮屏 -> 前台服务 -> 无障碍上划 -> 启动目标 App 链路。
- 每个任务可自由选择周一到周日的执行日期，支持“每天”和“周一至周五”等组合。
- 最近执行日志增加“一键复制全部”。
- 目标 App 打开后可继续执行可编排操作步骤：
  - 等待
  - 点击文字
  - 点击屏幕百分比坐标
  - 上/下/左/右滑动
  - 返回
  - 主页
  - 输入文字
  - 等待文字出现
- 自动化步骤会逐步写入执行日志，便于定位失败位置。
- v7.1：全部操作完成后约 60 秒自动执行“返回桌面”，让目标 App 退出前台；不会强制停止目标 App 进程。

## 自动化权限说明

为了实现“点击文字”和“等待文字出现”，v7 的无障碍服务需要在自动化任务运行期间读取当前窗口的无障碍控件树。Harmony Wake 不会把界面内容写入执行日志，也不会保存其他 App 的页面内容。

请不要把密码、PIN、短信验证码、支付凭据等敏感信息写入“输入文字”步骤。任务配置保存在应用本地 SharedPreferences 中。

如果设备配置了 PIN、密码或图案锁，Harmony Wake 不会尝试绕过系统认证。

## 华为 / HarmonyOS 建议设置

- 开启 “Harmony Wake 自动上划与操作” 无障碍服务。
- 应用启动管理中关闭自动管理，并允许：自启动、关联启动、后台活动。
- 关闭 Harmony Wake 的电池优化。

## 测试

每个任务都保留“10秒锁屏测试”。该测试会走与正式任务相同的广播、亮屏、解锁、启动和自动化链路，但不受星期设置限制。
